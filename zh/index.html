优先复用已有成果

演示沿用已有界面和验证结果，没有重新构建模型或索引。

演示范围、数据与隐私

案例使用测试输入，不含真实学生个人信息。输入表单已替换为案例选择。选择和准备备注仅在浏览器中处理，不发送至产品 API 或生成 AI。网站访问记录遵循 GitHub Pages 托管服务的处理规则。

本站不包含完整官方 PDF、模型、知识库或向量索引，只展示原文摘录和官方外链。官方网站当前资料可能与本演示的固定版本不同。

问答区展示历史在线测试中选取的保存样例，不代表总体正确率或当前模型表现。本网站用于作品体验，请勿用于当前出愿决策。
