## 手填、重复字段与适配障碍

- 来源输入由设计预先审核提供。开发没有从整份 PDF 盲抽取，本轮不能据此宣称同任务的节省百分比。
- 中文名、准备步骤、注意事项和原文章节路径仍需明确整理；与 plan 核对说明、前端显示目录有重复表达。作者输入统一记录语义和来源，生成脚本重放配置绑定；前端仅使用经过身份约束的显示投影。
- 新 KB hash 影响原有记录的全部绑定。导入后必须整体重算 policy／plan 的来源、Fact 和文件 pins，不能只追加 E09／E10 后混用旧 candidate manifest。
- 现有三主题 policy／plan 的集合本身可扩展。本次不需要改引擎或生产 Schema；页面的固定“三个主题”和旧 snapshot 显示目录需要最小扩展。
- 指定模板未持有，字数、版式细目和具体截止时刻保持未知。准备自报不作为官方结论来源。
