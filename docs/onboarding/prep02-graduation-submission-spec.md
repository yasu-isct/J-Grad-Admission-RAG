# PREP-02：毕业日期与寄送提醒

状态：设计合并后唯一 Ready；由 M17 Main 实施，设计 Agent 独立验收。属于 M17；关联 #258。
前置：#254 / PR #256 已验收合并；设计基线 main `cd406405fcce1380e9bcb7f346b494e299dd9a3e`。

## 目标与范围

用户在原两校四步页面填写毕业日期、网上手续和材料寄送情况，即可看到还需要确认什么。
复用现有 ApplicantProfile、审核规则、中文材料指南、原文窗口、待办和可选报告，不新建流程。
本任务只接通 ISCT 已有毕业时间及提交进度；GSFS 保持原有三主题覆盖。
高级工具入口暂时保留，下一任务统一清理。笔试另项，不搭车实施。

## 用户看到什么

第三步原“学历”分组根据毕业状态显示“毕业日期”或“预计毕业日期”。新增“网上手续与寄送”折叠分组：
“网上注册、照片上传及缴费是否均已完成”“材料寄出日期”“材料实际送达日期”，都可留空。
只有已支持的个别审查路径显示可选“资格审查办理进度”：尚未申请／已申请，等结果／流程已完成／不清楚。
“流程已完成”明确只记录自报办理情况，不表示审查通过；不增加审批通过或自动资格认证功能。

第四步沿用现有卡片，增加独立“毕业与提交提醒”，不把这些计作新增材料件数。
重要提醒进入现有待办，点击可定位相应输入或结果；未知和明确缺项分开；已完成自报不代表学校受理。
示例（仅固定 ISCT 历史资料，日期按选择的入学批次绑定）：

| 输入 | 中文输出样板 |
|---|---|
| 2027年4月入学，预计2027-03-20毕业，普通毕业路径 | “预计毕业日期在本批次规定期限内。这里只核对毕业时间，学历资格仍需结合其他条件确认。” |
| 同一目标，预计2027-04-10毕业 | “预计毕业日期晚于本批次要求的2027年3月31日，请向学校确认适用的申请方式。”不输出整个人无资格 |
| 仅填写2026-06-09寄出 | “已记录寄出日期，送达情况尚未确认。请核实材料能否在6月10日前送达；当天寄出不等于按时送达。” |
| 网上手续完成，送达日期为空 | “网上手续已完成；仍需确认纸质材料送达情况。” |
| 2026-06-10实际送达 | “按你填写的日期，材料在公布的接收期间内送达；是否受理请查看学校通知。” |
| 到达早于6月4日／晚于6月10日 | 分别说明早于接收期／晚于必着截止，不把两者都写成超期，也不替学校判受理 |
| 预计毕业或到达日期未知 | “补充预计毕业日期”／“确认材料实际送达日期”，不写成没有毕业或未送达 |

寄送中文说明复用 p.9：须邮寄，不能窗口递交，速达挂号；6月4日是建议尽早送达日，6月10日是必着截止。
说明不要把建议日期升级为强制要求，不自行推算物流时间或输出“现在还能赶上”。
报告保留原按钮与主题选择。仅选择“关键时间”时可写官方时间要求，不输出个人材料准备结论；
仅选择“材料”时可列提交提醒；个人毕业/办理进度只进入用户已选择的个人准备/待办主题，不因新增功能强制导出。
正文、复制文本均用简短中文，无内部字段或证据链；后台证据及页面原文入口保留。

## 字段合同与兼容性

在现有个人对照请求增加可选顶层 `application_preparation`，沿用 PREP-01 可选扩展方式；
新响应可选 `application_preparation_result`。未传新组，保持旧请求、响应缺省形状、统计及报告行为；
不得把新增结果塞入旧严格枚举或把未知布尔转 false。新组传入但全空时返回待补信息，不等同未选择功能。

| 新组字段 | 类型 | 映射至已有 Profile |
|---|---|---|
| completion_date | ISO date / null | academic_credentials[0].completion_date |
| expected_completion_date | ISO date / null | academic_credentials[0].expected_completion_date |
| individual_review_status | not_requested / requested / completed / null | eligibility_facts.individual_review_status |
| materials_dispatched_date | ISO date / null | application_submission.materials_dispatched_date |
| materials_arrival_date | ISO date / null | application_submission.materials_arrival_date |
| online_steps_completed | bool / null | application_submission.online_steps_completed |

日期与现有 completion_state 对应：completed 只接受 completion_date；expected 只接受 expected_completion_date；
其他/未知状态不接受两种日期。日期先后矛盾（到达早于寄出）返回就近可理解的校验错误。
不根据选择“外国16年”等标签偷偷补 country、years_of_education 或审查通过。审查状态不补写两个旧布尔字段。
不新增核心 ApplicantProfile Schema，不修改冻结审核规则。新组不支持的资料身份返回明确未覆盖，不套 ISCT。
源身份由服务器选择和核验，不能接受客户端自选 evidence/rule_id 来证明结论。
复用已验证的报告/证据检查路径，避免英语与新结果重复加载、重新审核同一来源；不强制另造推理引擎。
暂停的 QA #233/#236 不扩展，本任务不改变自由问答的 profile 合同或检索策略。

必须提交精确字段→规则→证据→中文输出表。真实资产定向测试涵盖：

1. 旧请求与新组缺省兼容；新组全空、false、日期冲突；未知/错误机构与资料身份不串用。
2. April正常/晚毕业、Sep普通期限边界及9/28–9/30特殊联系、未知学历与两条个别审查路径。
