# EVID-UI-01：多文件依据关系与按需原文弹窗

Issue [#240](https://github.com/yasu-isct/J-Grad-Admission-RAG/issues/240)。状态：Planned/Blocked by REPORT-02 [#239](https://github.com/yasu-isct/J-Grad-Admission-RAG/issues/239)，未Ready。M17范围；不依赖恢复QA-01。不同时修改REPORT-02使用的app.js。

## 背景、目标和复用

使用者看到同一材料后列了三个来源按钮，很难理解为什么需要三份文件。用户要求以可视关系表示，并在点击按钮后打开原文小窗口。主页面只呈现短结论、来源作用和关系；不铺长引文，不把证据链塞回简洁报告。

复用`material_slice_report.py`校验后的`ReviewedMaterialSliceEvidence.relations`与records、`reference_workspace.py`的同一snapshot响应、`unified-core.mjs`映射、`app.js::openDemoEvidence`及现有模态原文查看器。现有plan已审核5条关系；不让LLM生成关系，不建立图数据库、PDF解析器或新前端框架。设计示意见[阅读体验设计](reader-report-and-evidence-design.md)。

## 范围与兼容要求

1. 每个当前主题“查看依据关系（N份文件）”按需展开一个简洁关系图；初始无长原文，图也可收起。文件节点显示简称、相关页、中文作用。结论沿用当前有效结果，无个人条件时不得偷调用报告或伪造已判定状态。
2. 后端公开证据DTO当前没有relations。只允许为已有GET增加默认空的可选展示关系字段，复用同次已验证bundle，不改变canonical报告、plan/trust/hash、规则或生产Schema。字段绑定同一snapshot/revision，from/to必须是本次可见记录；客户端兼容字段缺失，缺失就显示独立卡片而非猜边。检查现有调用方兼容，不静默破坏严格客户端；若确需不兼容修改交设计处理。
3. 箭头方向与审核关系一致，显示中文意义。直接依据/关联上下文/入学手续相关分别标记。`shares_employment_context_but_separate_enrollment_stage`显示虚线和阶段提示，不能画成出愿必交关系。未知relation kind保留来源卡并说明关系未展示，不编故事。
4. E03→E01→E02示例实际是送付参照→按专攻确认→专攻直接条款，绝非三份文件都要求提交英语成绩单。E04→E05是参照检查表与提交表本身不同；E08→E06补充条件与上传方式。逐条给出可审查映射表。
5. 同文件可分组，但保留不同条款/页/阶段，不因三份文件常见就固定三节点。每个“查看原文”复用原模态窗口，显示文件标题、物理/印刷页、绑定片段与官方PDF入口。不打开新浏览器标签替代原文窗口；从窗口主动打开官方PDF沿用既有安全链接。
6. 无多个模态框堆叠，支持Escape、关闭按钮、焦点返回原触发节点与键盘访问；手机使用纵向卡片/连线，自适应窗口。图不得依赖颜色单独表达含义。切学校/版本/主题时关闭或作废旧图与原文，迟到GET不能污染新目标。

非目标：新募集要项/新规则/完整东大学生清单/高亮坐标/MinerU/报告改版/付费模型/知识图谱平台。ISCT已有原文查看和报告入口兼容，底层authority不变。

## 验收证据、资源与回滚

- 先用已有真实保留响应和校验产物定位relations在服务投影中的来源；给出每条图边与计划/记录绑定的对照，不以手填图冒充真实生成。
- 六类定向场景：三来源真实英语主题、检查表参照/提交关系、计划书出愿与入学阶段、缺失/未知关系、同文件不同页、多目标/迟到响应。图中文字、按钮打开的原文与对应记录精确一致。
- 桌面1440/手机390真实浏览器展示3个GSFS主题；验证收起/展开、每类节点原文、Escape与焦点返回、零额外自动报告调用。保留真实/合成/重放证据标签，不改原始摘录来适应图。
- 复用reference_workspace/API、unified-core、原文窗口和UI-02浏览器测试；服务schema添加字段须覆盖旧字段缺失兼容与snapshot错配。CI与定向检查通过后独立设计审查。
- 预算在本任务Ready时生效：开发/设计各最多2次自有服务启动、3次既有GSFS报告尝试用于条件结果对照、4次基础/个人POST；GET在会话内按需，30分钟/会话，RSS12GiB/可用4GiB。在线模型/搜索/下载/解析/构建0；不借QA剩余额度，不重置其他台账。只读既有资产、模型不必加载；前后身份核验与REPORT-02相同。
- 缺关系时展示独立来源卡，缺原文时说明不可用，不把片段或错文档补作依据。回滚仅撤销关系展示和可选DTO字段，保留原查看器、REPORT-02简洁报告、已审核资料。
