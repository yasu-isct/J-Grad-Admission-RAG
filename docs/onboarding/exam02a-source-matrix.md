## 来源缺口与停用边界

- `地球生命コース` 在地球惑星、応用化学、生命理工三系指向另一招生 PDF；本轮未持有该原件，课程分支的考试安排保持未核实，不能继承系表。
- 建筑的 A/B **专门科目**和 A/B **考试日程**是两个不同维度；导师指定与申请时选择无法从当前目录恢复。未取得这两个输入时，只能显示并列候选和需核对提醒。
- 机械和応用化学的系网页另载入试详情，当前不下载网页；本册未载的细目、选答数、科目题型保持空值。
- 物理、土木等英语成绩单时点与通常出愿时提交规则不同；必须继承本系原文限定。数学没有外部英语成绩单，不能由通用英语卡推出缺材料。
- 391 KB 有重复／混合表格 Fact，部分主 Fact 的 `fact_type` 为 `english` 却含考试表；只看类型或文本检索不得批准字段。此账本以原 PDF 页表格、学院／系身份和 Fact 定位共同校准。
