# EXAM-01：信息一览中的笔试信息

状态：Blocked，等待 PREP-02、TOOLS-01及设计的原页/年份/字段映射审核，不是当前开发任务。
属于 M17，实施方 M17 Main；先覆盖既有 ISCT 信息工学系固定资料，不能声称所有学科或东大支持。

## 用户目标

用户不必向聊天助手反复问“考什么”，第二步信息一览就能稳定看到考试科目、日期、时长、配分与注意事项。
沿用原四步页，在日期和材料旁增加“考试安排”卡；可选报告增加独立“考试安排”主题，用户勾选才导出。
不替代或改造RAG，也不为每次显示调用模型。其他学科尚未整理时明确“本项目尚未整理考试安排”，不能写“没有笔试”。

fact:00289 为口述名单公告，fact:00290 为过去问入口。源身份复用PREP-02固定PDF/KB，禁止重新构库。

## 数据与技术方案

复用既有Fact、页码、身份校验及中文展示配置；增加小型、版本绑定的已审核考试展示配置，
不修改原KB/fact/向量，也不将所有内容硬编码在HTML。配置需要可读字段：
institution/document/PDF和KB身份、学院/系、学位、适用入学批次、考试日程A/B、考试类型、
日期/开始结束/时长、科目组、题目数及表述、语言、配分、英语方式、注意事项、每项evidence绑定。
具体字段名与可选响应合同在放行前冻结；缺失字段保持未知，不能补0、推算分数或创建资格规则。

不要新增平行学校服务/问答prompt或大依赖。原文仍按钮打开原窗口，报告正文无需证据链。
