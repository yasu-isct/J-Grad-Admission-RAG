## 正式主问题：只用这三题

### Q1：用通俗语言解释一个概念

直接复制：

> 托业是什么

展示价值：用户不必先掌握日文招生术语，也能开始咨询。

合格要点：用简短中文解释 TOEIC 是英语能力考试，说明常见 L&R 是听力/阅读；
不应堆招生原文，也不能由定义推断所选专业必须提交托业。措辞不要求逐字一致。
预期是一次 planning 调用、没有学校资料检索/final调用。

演示时的讲解：“一般概念由助手解释；涉及某个学校的具体要求，则需要查官方资料。”

### Q2：查出申请时间并解释实际行动

直接复制：

> 按这份募集要项，网上登记最早什么时候开始？纸质材料什么时候必须送到？“必着”和当天寄出有什么区别？请用三条说明。

展示价值：把募集要项中的时间和术语，变成学生能理解的准备行动。

依据与判分锚点：现有已核验KB的“（１）出願期間”，官方PDF物理第9页：

- 网上出愿信息登记最早 **2026年6月1日9:00** 开始。
- 文件所述出愿期间为 **2026年6月4日至6月10日，必着**。
- 必着表示截止日前送达，不能把6月10日当天寄出说成符合要求。
- 该条未给出6月10日具体截止时刻；不得自行补17:00、23:59等时间。
- 不把网上登记开始、纸质材料期间和最终完成申请合成同一概念，也不擅自推断网上截止时刻。

预期两次模型调用：规划 → 既有目标内检索 → 整理。用当前结构化日期与第9页作人工核对，
不以模型给出的页码或另一模型判断替代核对。第9页原文已通过保留的真实离线响应与KB逐字验证，
本问题集未进行新PDF解析或问答请求。

讲解：“系统把几个容易混淆的时间分开，老师还可以打开原文核对。”

### Q3：混合问题，既能整理也能承认资料不足

直接复制：

> 托业840按官方的标准是多少英语配点，还有没有jlpt成绩，j-test可以吗

展示价值：处理学生一次提出的多个问题，并区分可解释的概念与尚未确认的学校规则。

合格要点：分别回应英语配点、JLPT和J.TEST，不只答其中一项；表达清楚、分点可读。
按照现有 [#163 覆盖缺口](https://github.com/yasu-isct/J-Grad-Admission-RAG/issues/163)：

- 不得给出“托业840必然等于最终英语X分”的数值；现有审核范围没有目标专业的最终配点公式。
- JLPT/J.TEST 的要求、接受或替代关系没有得到当前审核资料确认；应明确未确认。
- “当前资料未确认”不等于“学校不接受”“不需要提交”或“可直接替代”。
- 可以提供一般考试概念；不能靠模型常识补成学校官方规定。

预期最多两次模型调用。若只给笼统“请自行确认”而没有分别整理三个问题，仍需记录可用性不足。
本题不是展示系统已经知道所有规则，而是展示它能明确区分知道与不知道。

讲解：“老师能马上看见哪些内容有资料支持、哪些还要确认，避免把猜测转告学生。”

### Q2-R：原样重复 Q2，验证缓存

缓存会过期，服务重启也会失效；不要向听众承诺所有新问题都瞬间回答。
明天实际演示前如需重新运行，另计真实请求/费用，不把这次测试授权当作持续演示授权。
