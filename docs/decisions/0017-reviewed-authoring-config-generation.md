# ADR 0017：从已审核整理输入机械生成隔离配置

日期：2026-10-05。状态：M19设计接受，实施与效果待独立验收。范围：一个真实新材料及旧四主题兼容；不改变生产数据模型、规则执行和reference_only边界。

## 问题

M18已统一展示生成，但同一材料仍需在authoring、导入配置、policy来源bindings、plan文案/范围和展示映射间反复对应，容易漏表头、错版本或造成文案不一致。仅增加材料卡不能证明接入方式改进。

## 决定

使用一个开发期、有限配置生成器，将显式审核输入转换成既有格式。新真实样本为东大CBMS修士一般选拔A的志望调查表。原文保存在seed，中文语义/指南保存在单一authoring，批准来自设计提交的外部精确hash合同。

```text
锁定原PDF → 设计审核片段seed + 语义authoring + 外部批准
                    ↓ 核对身份、hash、完整引用
              有限配置生成器
                    ↓
既有import config → 原mapper/不可变候选与lineage
                    ↓ 机械引用绑定
既有policy/plan → 原条件与报告模块
                    ↓
M18展示目录 → 原四步页、原文窗口、个人自报、报告
```

生成器只支持本任务审核的明确条件模板，不从中文猜条件，不使用eval、任意表达式或新规则DSL。旧四主题基于已验收policy/plan重绑派生身份，业务语义不改；不一次迁移全部历史资料。

KB/Fact/hash/lineage是机械生成信息，不能由Agent手填副本。作者指南同一字段生成到多个消费者，不在各输出中再次独立编辑。旧条件及文案复用仍须完整版本校验。

## 审核与信任边界

外部批准先于生成输入存在并精确匹配；工具不能修改批准文件或仅校验自签manifest。允许为本包隔离预览生成新格式兼容的hash/trust绑定，但这些文件和最终实现必须在PR独立验收。计算hash不是授予可信状态，生产启用不是生成的副作用。失配时拒绝，不自行刷新批准。

摘录revision=3，原PDF/source-set仍s1 revision=1；新候选和snapshot有新不可变身份。旧v1/v2、334/391及原配置不覆写。兼容派生保留原作者来源和新版本依赖，不伪造旧作者在新版本上已审过。

## 代价、验证与回退

保留人工审核原文、中文解释、条件、例外和完整上下文。输入格式增加约束，应换来人工维护输出位置减少，而不是把重复移到其他JSON。工具正确性、模板边界和多版本兼容须验证。

本试验不是自动抽取新PDF、全校扩展或年度迁移。保留原文与结构供未来检索，不只存中文摘要；不引入图数据库或embedding模型。向量构建由独立检索任务决定。

[M19完整Spec](../onboarding/m19-authoring-to-config-spec.md)要求一个真实新材料闭环、生成可重现、外部批准失配负例、合成换目标、单字段同步、旧两校回归、维护位置及计时证据。不以测试数或抽象程度代替实际成果。

回退M19代码/新配置接入可恢复旧路径，保留全部资产与候选。无新激活配置时原在线服务不变。
