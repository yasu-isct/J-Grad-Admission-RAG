# インストール不要の公開体験デモ

**[ブラウザで開く](https://yasu-isct.github.io/J-Grad-Admission-RAG/)** · [README](../../README.md)

日本語の紹介ページから、既存の中国語・二校四ステップ UI を操作できます。2026年10月16日公開。

## 体験できること

| 対象 | 保存済みのサンプル |
| --- | --- |
| 東京科学大学・情報工学系・2027年4月入学・B日程 | 入学願書未準備と英語証明確認中／書類発送済みで到着未確認／卒業予定日と手続きの注意 |
| 東京大学・新領域・複雑理工学専攻・2027年度修士一般A・4月入学 | 在職継続／現在は在職していない例。限定5材料テーマ |

原文の抜粋、複数文書の関係、準備事項、参考レポートのプレビューとコピーを試せます。保存済み QA は東京科学大学の過去の検証例3件に限定し、現在の検索結果や品質評価と混同しない表示にしています。

## 実システムとの違い

このサイトは **静的な保存結果の再生** です。自由入力による資格照合、リアルタイムの RAG 検索、生成 API は実行しません。シナリオ選択で表示する保存済み結果を切り替え、レポートの表示・コピーには既存フロントエンドを再利用します。

当該資料は固定した過去版です。現在の出願の判断には使用しないでください。公式 PDF 全体・KB・モデル・ベクトル索引・実在学生の情報・秘密情報は公開サイトに含めません。根拠の抜粋と公式リンクを保持します。

## 実装と検証

- 再利用元は `33a473bdb78a6fc08f8e853c192c951bd115d9ad`。元の四ステップ画面とレポート・根拠表示を使い、デモ専用のアダプターを追加。
- PREP-01/02、EXAM-02B、M19、QA-01 online-20 の既存公開記録を利用。[出所と変換記録](https://yasu-isct.github.io/J-Grad-Admission-RAG/provenance.json)に元ファイルとハッシュを記録。
- デスクトップ1440px・モバイル390pxで全5シナリオ、合計10経路の実ブラウザ検証。公開URLでもログインなしで再検証。
- 参考レポートのプレビュー・コピー、関係図から原文への往復、学校切替時の旧状態消去、問答例の学校分離を確認。コピー文にも「演示样本 / 保存済みサンプル」を付与。
- 横方向のページはみ出し・JavaScript例外なし。製品POST・外部ランタイムリクエスト・付費呼出し0。
- [検証記録](public-demo-validation.json)。これは静的デモの検証であり、本体の新しいオンライン推論評価ではありません。

## 公開と保守

GitHub Pages は製品 main と独立した `gh-pages` ブランチのルートを配信します。公開コミットは `f050a911450a46e9fb29b82b7f6e9553b72507e7`。配信対象は約1MBの静的ファイルのみ。GitHub Pages のアクセス情報はホスティング提供者の取扱いに従います。

更新時は、対応する対象・入力・保存結果・表示コードの組合せを再検証します。単に最新 main の画面だけ差し替えません。戻す場合は過去の確認済み配信内容を新コミットで復元するか、Pages を停止します。

この作品デモの公開は、停止中の M13 バックエンド配備の再開ではありません。334回帰基準と391製品資産、既存サービス、モデル、自然言語回答の責任境界は変更しません。
