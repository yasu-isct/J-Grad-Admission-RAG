## 実システムとの違い

このサイトは **静的な保存結果の再生** です。自由入力による資格照合、リアルタイムの RAG 検索、生成 API は実行しません。シナリオ選択で表示する保存済み結果を切り替え、レポートの表示・コピーには既存フロントエンドを再利用します。

当該資料は固定した過去版です。現在の出願の判断には使用しないでください。公式 PDF 全体・KB・モデル・ベクトル索引・実在学生の情報・秘密情報は公開サイトに含めません。根拠の抜粋と公式リンクを保持します。
